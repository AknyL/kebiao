# 课表 · 今天有什么课

一个单页课表工具，数据只存在本机浏览器里，离线可用，可添加到手机主屏幕。

课表数据来自学校教务系统（kxjs.wmu.edu.cn，2026-2027 学年第一学期），含每节课的真实上下课时间、周次与单双周。

## 功能

- **今天**：正在上的课 / 下一节课，含距离上课/下课倒计时；下面列出今天的课和明天的课（按当前周次过滤，没课的周不会出现）
- **本周**：周一到周日整周课表，按天分组，只显示本周实际要上的课
- **查课**：一句话查询
  - `今天` `明天` `后天`
  - `周三` `下周三` `本周` `下下周`
  - `明天第3节` `周四上午` `晚上` `第8节`
  - `英语在哪上` `解剖` `体育`
  - `这周几节课`
- **课程**：增删改课程（含周次，写 `3-16` 或 `3,5,7`，留空=每周）、查看上课时间表、导出 `.ics` 日历（导入手机系统日历可获上课提醒）、导出/导入备份 JSON
- **智能导入**：「导入」页（顶部第五个标签）直接粘贴课表文字、CSV/TSV 表格或 JSON，也能选 `.txt/.csv/.json` 文件
  - 想要一个自己的固定入口：打开 `https://aknyl.github.io/kebiao/?import`（或末尾加 `#import`）会直接停在这一页，收藏即可
  - 每行一门课即可，能认出 `周一` `星期三`、`第3节` `3-5节`、`10:10-11:35`、`第3-16周`
  - 行里带 `https://…dingtalk…` 之类的钉钉/直播链接，会自动挂到这门课上，课程卡片出现「🔗 上课」，点开直接进课堂（导出 .ics 时链接也会写进日历事件）
  - 同名同天的课已存在时只补链接，不会重复添加；可选择「追加」或「覆盖全部」
  - 钉钉里的课表如果是网页，直接全选复制页面文字粘进来即可（浏览器不允许跨站读取钉钉页面，所以是「粘贴」而不是「填网址自动抓」）

## 周次

第 1 周从 2026-09-07 那周开始，页面顶部和「本周」都能看到当前是第几周。课程卡片上会标出「第5–8、10–16周」「第6–10周 双周」这样的上课周次。


## 上线方式

静态站点，直接托管即可（当前部署在 GitHub Pages）：

- https://aknyl.github.io/kebiao/

## 给 iPhone 用

1. Safari 打开上面的网址
2. 点「分享」→「添加到主屏幕」
3. 以后从主屏幕图标打开就是全屏 App 的样子

安卓：Chrome 打开 → 右上角 ⋮ → 「添加到主屏幕 / 安装应用」。

## 提醒

网页版做不了后台推送提醒（尤其是 iOS）。想要上课前响铃：在「课程」页点 **导出日历(.ics)**，把文件用「日历」App 打开导入，系统日历会在每节课前 10 分钟提醒。

## 文件

- `index.html` 单文件应用（界面 + 逻辑 + 默认课表数据）
- `manifest.webmanifest` / `sw.js` PWA 配置与离线缓存
- `icons/` 图标
