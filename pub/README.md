# 课表助手（公开版）

一个**不用登录、不联网、不收集数据**的课表小工具。所有课程只存在你自己手机/电脑的浏览器里。

线上地址：<https://aknyl.github.io/kebiao/pub/>
使用说明：<https://aknyl.github.io/kebiao/pub/help.html>

## 怎么用

1. 打开地址 → 点「导入课表」
2. 把课表**整段复制**进来（钉钉/教务系统导出的文字、CSV、Excel 复制的表格都行）
3. 点「解析预览」，确认解析结果
4. 点「追加」（推荐，不会覆盖已有课）或「覆盖全部」

也可以手动点「+ 添加课程」。

## 支持的课表写法

```
周一 第1-2节 高等数学 张三 A101
星期三 10:10-11:35 英语（1） 李四 2416 第3-16周
周四 第3节 体育 操场 https://h5.dingtalk.com/xxx
```

能自动认：

- **星期**：周一 / 星期三 / 礼拜五
- **节次**：第3节、3-5节
- **时间**：10:10-11:35
- **周次**：第3-16周、3,5,7周（留空 = 每周）
- **链接**：行内的钉钉/直播地址会自动挂到这门课，上课时点「🔗 上课」直接进
- 课程名不认识时，会按「教室编号 / 人名」把结尾拆成教室和老师

## 其他功能

- **今天 / 本周 / 查课**：一句话查课（「明天第3节」「周三下午」「英语在哪上」）
- **作息 / 学期**：在「课程」页改第 1 节开始时间和每节时长对应的节次时间，以及开学日期（影响「第几周」）
- **导出日历(.ics)**：导进手机系统日历，上课前能响铃（网页版做不了后台提醒）
- **导出备份 / 导入备份**：换手机时用 JSON 搬家
- 支持「添加到主屏幕」，离线可用

## 隐私

没有服务器、没有账号、没有统计。课程存在浏览器 `localStorage` 里，清空浏览器数据会丢，记得偶尔导出备份。
