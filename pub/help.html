课表助手 · 使用说明

免费 · 不用登录 · 课表只存在你自己的设备上

1这是什么

一个小网页，把课表贴进去，它就会告诉你今天有什么课、下一节在哪上、什么时候下课，上课前还能点链接直接进钉钉课堂。

没有账号、没有注册、没有服务器：课程只保存在你手机/电脑的浏览器里，换设备用「导出备份」搬家。

网址：https://aknyl.github.io/kebiao/pub/

230 秒上手

  1. 打开上面的网址
  2. 点首页的「导入课表」（或底部「导入」标签）
  3. 把课表整段粘贴到输入框
  4. 点「解析预览」→ 看解析对不对 → 点「追加」

之后每次打开就是「今天」页，不用再导入。

3课表从哪来

钉钉（最常见）

钉钉里打开「课表」→ 右上角 → 选「复制全部」或直接长按选中课表文字复制 → 粘贴进来。如果课程后面带着上课链接，也会一起识别，之后每节课都能点「🔗 上课」直接进。

教务系统网页

在电脑上打开教务系统的课表页，用鼠标把整张表框选复制，直接粘进来即可（一行一门课最好）。

Excel / 表格

把表格复制进来，或者「选文件」上传 .csv / .txt。表格要有表头，含「课程名」这一列即可，另外认「星期 / 开始节 / 结束节 / 教室 / 老师 / 周次 / 链接」。

什么都没有

点「课程」页 →「+ 添加课程」，手动填。也可以用地址栏直达导入页：/pub/?import

4认得的写法

每行一门课，下面这些信息写不写都行，写了就自动认：

周一 第1-2节 高等数学 张三 A101
星期三 10:10-11:35 大学英语 李四 2416 第3-16周
周四 第3节 体育 操场 https://h5.dingtalk.com/xxx
周五 第5-6节 大学物理 王五 实验楼302 3,5,7周
信息写法
星期周一 / 星期三 / 礼拜五
节次第3节、3-5节、第1-2节
时间10:10-11:35（有具体时间优先用时间）
周次第3-16周、3,5,7周、单周/双周；不写 = 每周
教室A101、1201、实验楼302、操场
老师两个字到六个字的人名，或「张老师」
链接行内任意 http(s) 地址，自动挂到这门课
提示：课程名不认识时，它会按「教室编号 / 人名」把行尾拆成教室和老师；如果拆错了，导入后点课程改一下就行。

5平时怎么用

页面能做什么
今天正在上的课、下一节、距上课/下课还有多久、明天有什么
本周周一到周日整周课表，今天的课高亮
查课一句话问：「明天第3节」「周三下午」「英语在哪上」「这周几节课」
课程全部课程、添加/修改、作息与学期、导出日历/备份
导入粘贴导入、解析预览、追加或覆盖

点任意一门课可以改名字、时间、教室、周次和上课链接；改完自动保存。

6作息不对？

默认作息是第 1 节 08:00、每节 45 分钟。如果和你学校不一样：

  1. 进「课程」页 →「作息 / 学期」
  2. 「每节开始时间」按顺序填，逗号分隔，如 08:10,09:05,10:10,10:55,14:00
  3. 点「保存设置」

「开学第一周的周一」只影响显示「第几周」。如果你不按周次筛选课程，可以不管。

提示：课程里自己填了开始/结束时间的，以课程为准；只有没填时间的课才按上面作息推算。

7装到手机主屏幕

iPhone / iPad（Safari）

打开网址 → 点底部「分享」→「添加到主屏幕」→ 添加。之后像 App 一样全屏打开。

安卓（Chrome / Edge）

打开网址 → 右上角「⋮」→「安装应用」或「添加到主屏幕」。

装好后没有地址栏，断网也能打开（已缓存的课表照常显示）。

8想要上课前响铃

网页做不了后台提醒，但可以借用系统日历：

  1. 「课程」页 →「导出日历(.ics)」
  2. 把下载的文件发给自己（微信文件传输助手即可）
  3. 在手机上点开它，选「添加到日历」

日历里会按周生成事件，自带 15 分钟前提醒，还能同步到手表。

9备份与换手机

数据只在这台设备的浏览器里，清除浏览器数据 = 课表丢失。建议：

  • 「课程」页 →「导出备份」，存一份 JSON 到网盘/微信收藏
  • 换手机时，新手机打开网址 →「导入备份」选那个 JSON

10常见问题

粘贴后一条都没解析出来？

检查每行是不是同时有星期或节次/时间——这两样至少要有一个，否则分不清是哪天的课。表格形式就带上表头。

时间显示成 --:--？

这门课的节次超出了你设置的作息行数。去「作息 / 学期」补上时间，或直接在这门课里填开始/结束时间。

周次显示「本周不上」？

多半是「开学第一周的周一」不对，改一下那个日期即可。

导入后重复了两遍？

用的是「追加」，同一门课同一天会自动去重只保留一条；如果还是重复，点课程删掉多余的那条，或先「清空课表」再重新「追加」。

会不会泄露我的课表？

不会。没有服务器、没有统计代码，数据不上传，也不会同步给任何人。
